## Context for Proxy Study
The EXE Portal rate limits OTP requests per IP. After 3 rapid registrations from same IP, OTP is blocked for ~29 minutes. The extension's natural delay (~60-90s per account due to Turnstile + verify) may stretch this slightly, but scaling beyond 3-5 accounts per session requires IP rotation. Chrome extensions can use `chrome.proxy` API to set proxy per-request. Study should cover: how to rotate IPs mid-batch, proxy auth in extensions, and cost-effective proxy options.
