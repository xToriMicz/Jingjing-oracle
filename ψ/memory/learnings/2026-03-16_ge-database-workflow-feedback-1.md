# GE Database workflow feedback: (1) ก่อนใส่ข้อมูล ต้องเช็ค format จาก data ที่มีอ

GE Database workflow feedback: (1) ก่อนใส่ข้อมูล ต้องเช็ค format จาก data ที่มีอยู่แล้วก่อนเสมอ (2) หลัง scrape ต้องสุ่มเทียบ 3-5 ตัวกับต้นทาง (3) ถ้าเจอขั้นตอนที่ช้าหรือซ้ำซาก ให้เขียนเครื่องมือขึ้นมาเลย ไม่ต้องรอ (4) D1 execSync ต้องใส่ maxBuffer สำหรับ query ใหญ่ (5) wrangler --file broken ต้องใช้ --command
