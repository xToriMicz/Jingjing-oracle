ทำงานเสร็จ → ส่งรีวิว + poll workflow:
✅ สร้างเสร็จ → maw talk-to sati-oracle ส่งรีวิว → ทำงานอื่นไป → poll oracle_thread_read ทุก 30 วิ → ได้ feedback → แก้ → ส่งกลับ → poll → ผ่าน → deploy → maw done
