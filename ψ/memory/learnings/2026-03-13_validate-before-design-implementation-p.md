# Validate before design: อย่าเขียน implementation plan ก่อนพิสูจน์ว่า core assump

Validate before design: อย่าเขียน implementation plan ก่อนพิสูจน์ว่า core assumption เป็นจริง ทดสอบ feasibility (PoC) ก่อนเสมอ ถ้าผ่านค่อย design + implement ถ้าไม่ผ่านหาทางอื่นก่อน invest time.
