# OG Tags ใส่ทุกเว็บเสมอ:

OG Tags ใส่ทุกเว็บเสมอ:
- og:title — ชื่อหน้า
- og:description — คำอธิบาย
- og:type — ประเภท (website, article, etc.)
ใส่ใน <head> ทุกครั้งที่สร้างเว็บใหม่
