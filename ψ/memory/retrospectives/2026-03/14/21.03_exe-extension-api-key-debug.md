2. **ไม่เช็ค build timestamp ตั้งแต่แรก**: เวลา extension มีปัญหา สิ่งแรกที่ควรเช็คคือ build ตรงกับ source มั้ย — ฉันไปเช็ค Worker, API key, route ก่อน ซึ่งไม่ผิดแต่ช้ากว่าที่ควร

3. **API key ควร manage ดีกว่านี้**: key อยู่ใน `.env` ลึกใน lab directory — ไม่มี central secret management Gabbzaa ต้องจำเองว่า key อยู่ไหน ควรมี reference ที่ชัดเจนกว่านี้

## Lessons Learned

- **Plasmo extension: always check build vs source timestamp** — `plasmo build` ไม่ auto-rebuild, ต้อง build ก่อน reload ที่ chrome://extensions
- **Debug order for extensions**: build freshness → API reachability → auth → code logic
